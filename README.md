## ⚙️ Development & Build Setup

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

### Installation

1. **Clone Repository**:
   ```bash
   git clone https://github.com/seif-elmuselmani/MyProtofolio.git
   cd MyProtofolio
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   *Access local server at `http://localhost:5173/`*

4. **Build Production Bundle**:
   ```bash
   npm run build
   ```

## 🌐 Deploying to Production (Vercel / Netlify / VPS)

### Deploying on Vercel (Recommended)
This repository includes a pre-configured `vercel.json` file.
1. Push code to GitHub.
2. Import repository in [Vercel](https://vercel.com).
3. Vercel automatically detects `Vite` preset and builds the application seamlessly.

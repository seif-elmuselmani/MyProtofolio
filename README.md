# Seif Elden - Personal Portfolio 🚀

An interactive, responsive, and dynamic personal portfolio web application built with **React 18**, **Vite 5**, **React Router DOM**, and **Lucide Icons**.

## 🌟 Features
- **Modern UI/UX**: Premium aesthetic with dark/light dynamic glassmorphism and modern typography.
- **Dynamic Content Context**: Powered by `DynamicPortfolioContext` for seamless state management.
- **Full Showcase**:
  - **Projects**: Detailed interactive project cards and live demo links.
  - **Credentials & Certificates**: Interactive modal previews for certificates and badges.
  - **Testimonials & Social Proof**: Client/colleague recommendations with proof modals.
  - **Teaching & Presentations**: Workshop and presentation decks.
  - **About & Contact**: Resume modal, skills matrix, and interactive contact form.
- **Secret Admin CMS**: Built-in dynamic management suite.

## 🛠️ Tech Stack
- **Frontend Framework**: React 18
- **Build Tool**: Vite 5
- **Routing**: React Router DOM v6
- **Icons**: Lucide React
- **Styling**: Vanilla CSS (Custom Design System)

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js (v18+) installed.

### Installation & Run

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

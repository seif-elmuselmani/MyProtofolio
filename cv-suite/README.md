## 🚀 كيفية الاستخدام في Overleaf (في 30 ثانية):

1. افتح مشروعك في منصة [Overleaf](https://www.overleaf.com/project/6940b6397f4def5325b35804).
2. افتح الملف المطلوبة من مجلد `cv-suite/templates/`.
3. انسخ محتوى الملف بالكامل (`Ctrl + A` ➔ `Ctrl + C`).
4. الصق المحتوى داخل مشروع Overleaf واضغط على **Recompile** (أو `Ctrl + Enter`).
5. قم بتنزيل ملف الـ PDF الجاهز فوراً!

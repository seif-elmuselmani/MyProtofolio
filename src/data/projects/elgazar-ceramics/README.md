# معرض السيد الجزار للسيراميك والبورسلين (Freelance Commercial Project)

منظومة تجارية حية متكاملة تم تطويرها خصيصاً كـ مشروع لعميل حر (Freelance Production Client)، تخدم معرض "السيد الجزار للسيراميك والبورسلين وأطقم الحمامات والخلاطات".

## 🚀 الرابط المباشر للموقع الحي:
- **الموقع الرسمي الحي**: [elgazar-ceramics.store](https://www.elgazar-ceramics.store/)

## 🛠️ التقنيات المستخدمة:
- **Frontend**: React.js, TailwindCSS, Responsive Design, Lucide Icons, Vite.
- **Backend**: Node.js, Express.js RESTful APIs.
- **Database & Cloud**: MongoDB Atlas, Cloudinary Storage.

## ⭐ أبرز الإنجازات والخصائص الفنية:
1. **مشروع تجاري مسلّم لعميل (Freelance Client)**: بناء واجهة وتطبيق سحابي ديناميكي متكامل.
2. **كتالوج سحابي غير محدود**: إمكانية تصفح وإدارة عدد غير محدود من الأصناف والموديلات.
3. **لوحة تحكم إدارية (Admin Dashboard)**: إمكانية إضافة وتحديث الموديلات، الخصومات، والأسعار فورياً.
4. **حاسبة الأمتار والكراتين الفورية**: حساب الأمتار والكراتين والتكلفة الإجمالية فورياً للعملاء والمقاولين.
5. **التكامل مع WhatsApp و الـ QR Code**: إرسال الاستفسارات والطلبات فورياً لمسئول المبيعات، مع دعم الـ QR Code للتسويق.

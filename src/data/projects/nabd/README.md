## 🏛️ الأنظمة والموديولات الرئيسية (Core Modules)

### 1. بوابة المريض (Patient Portal)
- البحث المتقدم عن الأطباء حسب التخصص، الموقع، والتقييمات.
- معالج حجز المواعيد واختيار الفترات الزمنية المتاحة.
- السجل الطبي الموحد (Unified Medical Passport)، الروشتات الرقمية، والدفع الإلكتروني.

### 2. وحدة الدكتور وغرفة الجلسات الحية (Doctor Command Center & Clinical Terminal)
- إدارة المواعيد وجداول العيادات متعددة الفروع.
- شاشة التشخيص المباشر وتوليد ملخص الـ SOAP (Subjective, Objective, Assessment, Plan).
- دمج نموذج الذكاء الاصطناعي (Mistral AI) لاستخراج الأعراض والتوصيات الطبية الفورية.

### 3. وحدة التحقق والإدارة (Verifier & Admin Module)
- فحص تراخيص الأطباء والمستندات الطبية واعتماد الحسابات.
- لوحة الإحصائيات المركزية ومراقبة العمليات في النظام.

---

## 🛠️ التقنيات والمعمارية البرمجية

- **Backend**: ASP.NET Core 8.0, C# 12, Clean Architecture, Entity Framework Core, SQL Server, PostgreSQL, JWT Authentication.
- **Frontend**: React 18, Vite 5, Tailwind CSS, Zustand State Management, Axios Interceptors.
- **AI Integration**: Mistral AI LLM & Gemma3-270M for natural language medical symptom extraction.
